# DESIGN.md 设计参考库(B2B/科技风精选)

> 来源:VoltAgent/awesome-design-md(74 个真实网站的设计系统分析)
> 精选 14 个适合 B2B 外贸/科技产品建站的风格
> 用法:vibe coding 建站时,把选中的 DESIGN.md 复制到项目根目录,AI 会按该设计语言生成一致 UI

## 风格速查

| 目录 | 风格 | 适合场景 |
|------|------|---------|
| linear.app | 极简深色科技、紫色 accent | AI/开发者工具、SaaS |
| vercel | 黑白极简、几何 | 开发者平台、技术产品 |
| clickhouse | 深蓝数据风 | 数据/分析产品 |
| stripe | 简洁渐变、紫蓝 | 支付/金融科技 |
| supabase | 深绿科技 | 开发者工具 |
| mongodb | 深绿丛林 | 数据库/基础设施 |
| nvidia | 深黑科技绿 | 硬件/AI/半导体 |
| hashicorp | 简洁蓝黑 | DevOps/基础设施 |
| cohere | 暖色 AI 风 | AI 平台 |

| ollama | 蓝灰极简 | 本地 AI 工具 |

## 使用方法

```bash
# 建站时选一个风格,复制到项目根目录
cp design-md/linear.app/DESIGN.md /your-project/DESIGN.md
# AI agent 读 DESIGN.md 后,所有 UI 保持该设计语言
```
